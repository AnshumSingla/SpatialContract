Target length **2:50** (hard limit 3:00). About 370 spoken words (roughly 2:30 of speech) leaving room for pauses on the screen. Screen recording only, **no music** and no logos: the words "Nemotron", "Nebius Token Factory" and "NVIDIA" appear as plain text, which the rules require. Public YouTube upload; put the repo link and the demo link in the description.

**Prepare before recording**
- Browser at the published demo page (or `docs/index.html`), window about 1280x720, zoom 110%.
- A terminal in the repo, font large, with `spatialcontract check examples/inmemory_example.py` and `python scripts/localise_real.py torchio_crop` typed but not run (the second takes about a minute; run it once beforehand and keep the output on screen if you prefer).
- Autoplay starts 3.5 s after selecting a chip: pause it immediately when you select a chip (click Pause), then press Play at 1:00 on the first chip.
