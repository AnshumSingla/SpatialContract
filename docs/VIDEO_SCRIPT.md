# 3-minute video script

Target length **2:50** (hard limit 3:00). About 325 spoken words (roughly 2:15 of speech) leaving room for pauses on the screen. Screen recording only, **no music** and no logos: the words "Nemotron", "Nebius Token Factory" and "NVIDIA" appear as plain text, which the rules require. Public YouTube upload; put the repo link and the demo link in the description.

**Prepare before recording**
- Browser at `docs/index.html` (or the published copy), window about 1280x720, dark or light theme either is fine, zoom 110%.
- A terminal in the repo with `python scripts/demo.py replay L04_right_multiply` ready (not needed unless the page misbehaves).
- First chip ("Unit tests pass. The landmarks are 100+ mm off.") selected. Autoplay starts 3.5 s after selecting a chip: pause it immediately for the first 30 s (click Pause), then press Play at 1:05.
