SpatialContract

An agent that repairs orientation and affine bugs in medical-imaging code. Nemotron proposes the fix; a physical-coordinate oracle with known landmarks verifies it.

Try it yourself

Steps 1 to 3 run on your machine with no API key, no GPU and no network after install.

  1. Install (Python 3.10+): 
    git clone https://github.com/AnshumSingla/SpatialContract
cd SpatialContract
python -m venv .venv
.venv/Scripts/pip install -e ".[dev]"      # Linux/macOS: .venv/bin/pip, then activate the venv
  2. Watch the oracle catch a bug. A buggy and a fixed crop, checked against landmarks at known physical positions: 
    spatialcontract check examples/inmemory_example.py::crop_buggy examples/inmemory_example.py::crop_fixed
    Prints FAIL worst landmark 25.3 mm off, a line naming the kind of mistake, then PASS worst landmark 0.00 mm off.
  3. Check your own pipeline. A script with a process(in_path, out_path) function that reads one 3D NIfTI and writes one declares what it promises at the top: 
    SPATIAL_CONTRACT = {
    "world_frame": "RAS",                          # or "LPS"
    "units": "mm",
    "affine_convention": "voxel_center_to_world",
    "array_orientation": "RAS"                     # optional
}

def process(in_path, out_path):
    ...                                            # your code, unchanged
    spatialcontract check my_pipeline.py      # exit 0 PASS, 1 FAIL, 3 ERROR, 4 ABSTAIN
    For an in-memory function, use the @spatial_contract(world_frame="RAS", units="mm") decorator or the spatial_oracle pytest fixture instead; examples/inmemory_example.py shows both.
  4. Let Nemotron repair it (needs a Nebius Token Factory key): 
    cp .env.example .env                                         # put your key in NEBIUS_API_KEY
SC_ALLOW_API=1 python scripts/repair.py my_pipeline.py --budget 30000
SC_ALLOW_API=1 spatialcontract init my_pipeline.py           # no contract yet? Nemotron drafts one
    Your file is never edited: every patch is written to results/runs/<run-id>/, and a patch counts as a repair only if it also passes hidden phantoms. init only prints a draft, quoting the source line behind each field, for you to confirm. Every call is capped by a token ledger. In PowerShell, set $env:SC_ALLOW_API=1 first.
  5. Keep it in CI. Copy examples/ci/spatialcontract.yml into .github/workflows/ to run the check on every pull request.

Sample inputs and outputs to open in ITK-SNAP or 3D Slicer are in samples/. Replay a recorded run in the terminal with python scripts/demo.py replay L04_right_multiply, or paste any script into the local web UI with python scripts/demo.py serve.
